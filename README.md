# Tree-Based Ensemble Methods: From Bagging to XGBoost
Exploring ensemble methods built on Decision Trees — Bagging, Random Forest, Gradient Boosting, and XGBoost — applied to a groundwater prediction problem.

## Problem
Predict Recovery Effectiveness (REN), the fraction of injected water recoverable from an aquifer after one year, using 7 hydrogeologic features (hydraulic conductivity, injection rate, porosity, aquifer thickness, groundwater gradient, dispersivity, and extraction-to-injection ratio). Training data: 5,000 simulations generated by MODFLOW and MT3D physics-based models.

## Results

| Model | MSE |
|---|---|
| Decision Tree (max_depth=6) | ~0.035 |
| Bagging (50 DTs) | ~0.019 |
| Random Forest (50 trees) | ~0.017 |
| Gradient Boosting — manual (3 trees) | ~0.022 |
| GradientBoostingRegressor (100 trees) | ~0.006 |
| XGBoost | ~0.007 |

**Top features (RF feature importance + SHAP):** groundwater gradient (CHD) and hydraulic conductivity (K) dominate REN prediction.
